PUBBLICAZIONE SU GITHUB PAGES

  2. "uploading an existing file" → trascina TUTTI i file e le cartelle,
     mantenendo la struttura: le pagine nella root, style.css in css/,
     le immagini in assets/img/.
  3. Settings → Pages → Source: branch main, /(root) → Save.
  4. Dopo 1-2 minuti: https://tuonome.github.io/enneagramma-sito/

GADGET BILINGUE ITALIANO / ENGLISH (DT25)
  Il sito resta interamente in ITALIANO, ma nel menu di ogni pagina
  compare il selettore di lingua con le bandierine 🇮🇹 / 🇬🇧
  (classe .lang-switch, a destra del menu). La bandierina 🇬🇧 apre la
  pagina tradotta da Google Translate (proxy translate.goog), la 🇮🇹
  torna all'originale italiano. Il selettore funziona su qualsiasi
  dominio (github.io o dominio proprio) perche' l'URL di traduzione
  viene costruito in JavaScript dal nome dell'host corrente.
  Non serve alcuna configurazione lato server: carica i file e basta.
  Nota: la traduzione e' generata da Google al volo sulla pagina
  pubblicata; la prima traduzione puo' richiedere alcuni secondi.
